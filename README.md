# BSwedding — Bala Bhavya & Sri Ram

A mobile-first luxury Indian wedding invitation built with Next.js, Framer Motion and custom responsive CSS.

## Included
- Cinematic invitation reveal and monogram intro
- Animated hero with editorial typography and layered motion
- Engagement and wedding event sections
- Live countdown to 13 December 2026 (10:00 AM IST placeholder; confirm actual muhurtham)
- Mobile navigation, responsive layouts and reduced-motion support
- RSVP / wishes email action

## Run locally
```bash
npm install
npm run dev
```

## Personalise before publishing
Update the engagement date, ceremony timings, venue names, map links and family message in `app/page.js`. Replace the Unsplash background URLs with approved couple photography. The engagement details, venue, exact wedding muhurtham and photographs have not yet been supplied and are intentionally marked as pending. The countdown currently uses 10:00 AM IST as a temporary display value, not a confirmed muhurtham.

## Deploy
Import this repository into Vercel and deploy with the default Next.js settings.
